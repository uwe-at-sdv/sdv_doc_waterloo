Tools
=====

This section is normative.

:wtrl_cmd:`waterlint` error codes
---------------------------------

The following error codes |must| be used by :wtrl_cmd:`waterlint` for JSON processing.

* [JSCH-000] -- Unspecified catch-all error.
* [JSCH-002] -- Cannot open the input JSON file for validation.
* [JSCH-003] -- Cannot infer the schema from the input JSON file.
* [JSCH-004] -- Input is not valid JSON.
* [JSCH-005] -- JSON validation against the schema failed.

* [JSCH-700] -- Unspecified exception during JSON rendering.
* [JSCH-800] -- Unspecified JSON schema exception.

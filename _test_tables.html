14. Test: Tables in freeform and itemized content¶

This section is informative.

Preamble

normative sections

  • Contract, Public classes, Public variables, Public types

Contract

general

  • Must demonstrate the HTML rendering of tables

Description

This module demonstrates the rendering of tables in the Sphinx extension and the pipeline JSON -> HTML5.

Tables can be used in the following sections:

  • Description

  • Definitions.<item>

  • Terminology.<item>

  • Notes.<item>

  • Factory.<item>

  • Class_overview.<item>

  • Function_overview.<item>

  • Method_overview.<item>

  • Returns

  • Parameters.<item>

  • Raises.<item> (allowed although item-like)

They are not allowed in lists of strings:

  • Preamble.*

  • Derived_from

They are not allowed in item-like (sub)sections like:

  • Contract.general

  • Contract.constructor

  • Contract.requires

  • Contract.ensures

  • Contract.invariants

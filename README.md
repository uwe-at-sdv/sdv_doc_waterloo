# IDE Plugins

This branch collects Waterloo tooling that is related to IDEs and editor
integration in a broad sense.

It currently contains:

- [`vscode/`](vscode/) for the Visual Studio Code extension
- [`pygments/`](pygments/) for the Pygments lexer

Use the subdirectories for implementation details, installation notes, and
package-specific documentation.

## Status

This branch is a working area for IDE-facing tooling. Individual components
may still be under active development, packaging changes, or release staging.
